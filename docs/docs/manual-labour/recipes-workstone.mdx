# Workstone
**Type:** `manual_labour:workstone`

This takes two ingredients (the item to process, then the tool/item applied to it) and an array of chance-weighted results.

Optionally, you can specify `"tool_use"`:
- `"damage"` (default): Uses 1 durability on the tool.
- `"consume"`: Consumes 1 item from the held stack.
- `"keep"`: Uses the item without consuming or damaging it.

For Create users, this falls back to Deployer steps in Sequenced Assembly, or the Mechanical Press. You can toggle this behavior with `use_create_deploying_recipes` and `use_create_pressing_recipes`. A Workstone recipe can also be a step in a Sequenced Assembly itself.

The file format is Create's processing recipe shape and does not change based on whether Create is installed.

This example lets you hammer cobblestone into gravel, with a 25% chance for an additional flint.

```json
{
  "type": "manual_labour:workstone",
  "ingredients": [
    {
      "item": "minecraft:cobblestone"
    },
    {
      "tag": "manual_labour:hammers"
    }
  ],
  "results": [
    {
      "id": "minecraft:gravel",
      "chance": 1.0
    },
    {
      "id": "minecraft:flint",
      "count": 1,
      "chance": 0.25
    }
  ]
}
```

## Combining with Create's Sequenced Assembly

With Create installed, a `manual_labour:workstone` recipe can be used as a step inside a `create:sequenced_assembly` recipe, alongside Create's own `create:deploying` steps. This lets you build recipes like "attach two ingots to an item, then hammer it into shape" for example.

A sequence only needs one manually-completable step (a `manual_labour:workstone` step, or a `create:deploying`/`create:pressing` step) to show up and be completable in Manual Labour. By default the deployed item (first ingredient) is consumed; add `"keep_held_item": true` to a `create:deploying` step to keep it, e.g. for a tool that shouldn't be used up.

This example turns an iron ingot into a chain by deploying two more iron ingots onto it, then hammering it:

```json
{
  "type": "create:sequenced_assembly",
  "ingredient": {
    "item": "minecraft:iron_ingot"
  },
  "transitional_item": {
    "id": "minecraft:iron_ingot"
  },
  "loops": 1,
  "sequence": [
    {
      "type": "create:deploying",
      "ingredients": [
        {
          "item": "minecraft:iron_ingot"
        },
        {
          "item": "minecraft:iron_ingot"
        }
      ],
      "results": [
        {
          "id": "minecraft:iron_ingot"
        }
      ]
    },
    {
      "type": "create:deploying",
      "ingredients": [
        {
          "item": "minecraft:iron_ingot"
        },
        {
          "item": "minecraft:iron_ingot"
        }
      ],
      "results": [
        {
          "id": "minecraft:iron_ingot"
        }
      ]
    },
    {
      "type": "manual_labour:workstone",
      "ingredients": [
        {
          "item": "minecraft:iron_ingot"
        },
        {
          "tag": "manual_labour:hammers"
        }
      ],
      "results": [
        {
          "id": "minecraft:chain"
        }
      ]
    }
  ],
  "results": [
    {
      "id": "minecraft:chain"
    }
  ]
}
```

The `create:sequenced_assembly` recipe type requires Create to be installed. If you want a sequence to work without Create, use Manual Assembly instead.
