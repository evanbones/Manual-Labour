# Millstone

The Millstone is a simple way to grind items down by spinning it.

> **Requires Create.** The Millstone is a kinetic machine that runs on rotational force and grinds using Create's Milling recipes, so it only exists when Create is installed. Without Create the block, its crafting recipe and its JEI category are all absent. Everything else in Manual Labour works on its own.

<PrefabObtaining />

## Usage

Throw or insert items on top to feed the Millstone. Once it is loaded, you just spin it! Fun fact, if you stand on top of it, you will spin along with it.

Once the items are ground up, right-click the Millstone with an empty hand to collect the results. Just be careful not to spin it too fast, or it will stop grinding.

If you remove Create from an existing world, any Millstones you have placed will disappear along with the block, exactly as with any other removed content.
