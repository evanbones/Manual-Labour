# Workstone

The Workstone is a super handy station for processing items by hand. Simply put an item on the Workstone, grab a Hammer, and give it a good whack! You will get some nice processed materials out of it.

<PrefabObtaining />

## Usage

To use the Workstone, place the block down and right-click it with the item you want to process. Then, take any Hammer and right-click the Workstone to hit the item. 

The Workstone works with or without Create, and comes with a full set of its own recipes either way.

If you do have Create installed, it picks up three extra tricks. It can stand in for the Mechanical Press, though hammering by hand yields a little less than the powered version would; it can complete Deployer steps inside a Sequenced Assembly; and it can be a step in a Sequenced Assembly itself. Each of these can be turned off under **Create Compatibility** in the config.
